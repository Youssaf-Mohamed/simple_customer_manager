# Simple Customer Manager

Simple Customer Manager is a lightweight PHP application for managing customer data with a clean, responsive interface.

## Features
- View customer details
- Calculate total customer balance
- Delete customer records with confirmation pop-ups

## Requirements
- PHP 7.2 or higher
- MySQL (or any PDO-supported database)
- A web server (e.g., Apache or Nginx)
